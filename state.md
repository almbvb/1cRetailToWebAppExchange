# Текущее состояние сайта

Задача: сайт-PWA доставки продуктов одного магазина и шаблон для других клиентов. Сайт — сторона «приложения» в обмене с 1С:Розница 2.3: принимает каталог, цены, остатки, картинки, статусы заказов; вызывает API 1С для проверки наличия и создания заказа. Бриф — `c:\_1c_edt\rt_httpsvc\collab\reports\0131_бриф_сайт.md`.
Роли: сессия сайта — ведущий (план, микрозадачи субагентам, проверка); сессия 1С — владелец контракта и папки `collab\`; пользователь — решения, приёмка этапов, тесты в 1С.
