# Запуск сайта на этом компьютере

Все команды выполняются в PowerShell из папки проекта:

```powershell
cd C:\_web\delivery_site
```

## Запустить

```powershell
.\scripts\start.ps1
```

Скрипт по порядку:
1. запускает базу PostgreSQL (порт 5433);
2. открывает **отдельное окно** с сайтом (backend, порт 8090) — это окно не закрывать, пока сайт нужен;
3. проверяет, что сайт отвечает, и пишет «Готово: сайт работает, база доступна».

С витриной (когда она появится, этап С2):

```powershell
.\scripts\start.ps1 -Frontend
```

**После перезагрузки компьютера** база и сайт сами не запускаются — снова выполните `start.ps1`.

## Адреса

| Что | Адрес |
|---|---|
| Обмен для 1С («Настройки обмена с приложением») | `http://localhost:8090/exchange/1c` |
| Админпанель (журнал обмена, каталог, заказы) | http://127.0.0.1:8090/admin |
| Проверка работы | http://127.0.0.1:8090/api/health → `"db": true` |
| Витрина (с `-Frontend`) | http://localhost:3000 |

## Логины и пароли

Все пароли — в файле `C:\_web\delivery_site\.env` (открыть Блокнотом). Файл не попадает в git.

| Где | Логин | Пароль — строка в `.env` |
|---|---|---|
| Настройки обмена в 1С | `onec_exchange` | `EXCHANGE_BASIC_PASSWORD` |
| Админпанель | `admin` | `ADMIN_PASSWORD` |
| Вызов API 1С сайтом (этап С4) | `app_api` | `ONEC_API_PASSWORD` — впишите сами |

Копируйте только то, что после знака `=`, без пробелов. Пароль обмена — 30 символов.
В форме настроек 1С после вставки пароля нажмите **Tab** (выйти из поля), затем **Записать**.

## Остановить

```powershell
.\scripts\stop.ps1
```

Останавливает сайт, витрину и базу. Оставить базу работать: `.\scripts\stop.ps1 -KeepDb`.
Можно также просто закрыть окно сайта.

## Проверить, что 1С обменивается с сайтом

Откройте админпанель → **Журнал обмена**. Каждый запрос 1С — строка: поток (каталог, цены, остатки,
картинки, статусы), код ответа, сколько записей, ошибка.

| Код | Что значит | Что делать |
|---|---|---|
| 200 | принято | — |
| 401 | неверный логин или пароль | проверить пользователя и пароль в настройках 1С (таблица выше) |
| 400 | 1С прислала данные не по контракту | сообщить в сессию сайта — текст ошибки в журнале |
| 413 / 415 | картинка больше 4 МБ или не JPEG/PNG | заменить картинку в 1С |
| 500 | ошибка сайта (часто — база не запущена) | выполнить `start.ps1`; 1С сама повторит порцию |

При любом ответе, кроме 200, 1С ничего не теряет: она повторит ту же порцию при следующем запуске задания.

## Если что-то не работает

- **«db": false» или сайт отвечает ошибкой 500** — не запущена база: `.\scripts\db.ps1 start`.
- **Порт 8090 занят** — сайт уже запущен (окно открыто) или висит старый процесс: `.\scripts\stop.ps1 -KeepDb`, затем `start.ps1`.
- **Порт 3000 занят** — его использует другой проект; остановите его или запускайте без `-Frontend`.
- **Скрипт не запускается: «выполнение сценариев отключено»** — один раз выполните
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
- **Повторить данные заглушки без 1С** (для проверки): `backend\.venv\Scripts\python.exe tools\replay_mock.py --verify`.

## Состояние базы

```powershell
.\scripts\db.ps1 status   # работает ли
.\scripts\db.ps1 psql     # консоль SQL (выход — \q)
```
